# 다나고한의원 홈페이지 (블루 브랜드 / 모바일 우선 버전)

## 구성 파일
- `index.html` : 홈페이지 콘텐츠
- `styles.css` : 파란색 브랜드 디자인 및 모바일 반응형 레이아웃
- `script.js` : 모바일 메뉴 및 연도 표시
- `danago-logo.png` : 전달받은 다나고한의원 로고
- `robots.txt`, `sitemap.xml` : 검색엔진 안내

## GitHub에 업데이트하는 방법
1. 이 ZIP 파일을 다운로드한 뒤 압축을 풉니다.
2. GitHub의 기존 `DANAGOHANI` 저장소를 엽니다.
3. `Add file` → `Upload files`를 선택합니다.
4. 압축을 푼 폴더 안의 파일 6개를 선택해 업로드합니다. 기존 파일과 이름이 같은 파일은 교체됩니다.
5. `Commit changes`를 누릅니다.
6. Vercel은 GitHub 변경 사항을 감지해 자동으로 다시 배포합니다. Vercel의 Deployments에서 완료 여부를 확인하세요.

## 배포 전 확인
- 네이버 플레이스 링크는 검색 링크를 사용하고 있습니다. 실제 예약 전용 URL이 있다면 `index.html`의 네이버 링크를 교체하세요.
- 주소의 호수 및 진료시간은 공개 안내 자료를 기준으로 한 초안입니다. 실제 정보와 일치하는지 확인하세요.
- 홈페이지는 정적 HTML이며 별도 빌드 명령이 필요하지 않습니다.
